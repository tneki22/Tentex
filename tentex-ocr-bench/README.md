# Tentex OCR Bench v2

Бенчмарк для оценки конвейеров, переводящих образовательные документы в Markdown + LaTeX. Версия 2.0 содержит 24 scored-pages и три пользовательских рукописных фото-референса без ground truth.

## Что проверяет v2

- обычные и деградированные сканы;
- телефонные фото с перспективой, тенью, неравномерной подсветкой, бликом, виньеткой и частичной окклюзией;
- dewarp: для страниц 11–16 известны точные координаты четырёх углов листа;
- оглавление с вложенными пунктами, точками-лидерами и номерами страниц;
- нативную ветку PDF: страницы 19–21 скомпилированы Tectonic из LaTeX, содержат извлекаемый текстовый слой формул и не содержат изображений;
- формулы, таблицы, рисунки, код, двухколоночную вёрстку, химические индексы и заряды, вложенные задачи, DOI/URL/ISBN и смешанную кириллицу/латиницу.

## Dewarp-разметка

Для каждой страницы 11–16 файл `photo_geometry/page_XX.json` содержит:

- размер исходного JPEG;
- `page_corners_px`;
- `page_corners_normalized`;
- порядок точек: top-left, top-right, bottom-right, bottom-left;
- список синтетических дефектов;
- номер чистой страницы-источника.

Это позволяет отдельно считать corner error / IoU листа и качество OCR до и после rectification.

## Пересборка

Требования: Python, PyMuPDF, Pillow, NumPy, Matplotlib, NetworkX и Tectonic 0.15+.

```bash
python3 build_benchmark.py
python3 write_ground_truth.py
python3 build_extension.py
python3 extend_ground_truth.py
python3 validate_benchmark.py
```

Tectonic должен быть доступен по `/agent/workspace/bin/tectonic` либо через переменную `TECTONIC`.

## Метрики

- Text Edit ↓ — нормализованное расстояние редактирования текста.
- CDM ↑ — точность формул.
- TEDS ↑ — структурное сходство таблиц.
- TOC tree score ↑ — совпадение иерархии заголовков и номеров страниц.
- Dewarp corner error ↓ — средняя ошибка четырёх углов листа.
- Native routing accuracy ↑ — выбор нативной ветки для страниц 19–21 без OCR.

## Важно о пользовательских примерах

Три фото конспектов сохранены в `reference_photos/` как неоцениваемые референсы реальных дефектов. Их автоматическая транскрипция не выдаётся за ground truth. Статус лицензии исходного PDF оглавления не подтверждён; перед публичной публикацией набора проверьте права на распространение или замените страницы 17–18 синтетическим аналогом. Подробнее — `SOURCES.md`.
