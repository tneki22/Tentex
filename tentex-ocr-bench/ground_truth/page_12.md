# § 12. Затухающие колебания

![Рисунок 12.2 — График затухающих колебаний; штрих — огибающая ±A₀e^(−βt)](figure_12_2.png)

Реальные колебательные системы всегда содержат диссипативные элементы, поэтому свободные колебания постепенно затухают. Простейшая модель — осциллятор с вязким трением, сила которого пропорциональна скорости: $F_{\mathrm{тр}} = -r \dot{x}$.

Уравнение движения принимает вид

$$\ddot{x} + 2\beta \dot{x} + \omega_0^2 x = 0, \tag{12.1}$$

где $\beta = r/2m$ — *коэффициент затухания*, $\omega_0 = \sqrt{k/m}$ — собственная циклическая частота осциллятора.

При малом затухании ($\beta < \omega_0$) решение уравнения (12.1) имеет вид

$$x(t) = A_0 e^{-\beta t} \cos(\omega t + \varphi_0), \qquad \omega = \sqrt{\omega_0^2 - \beta^2}, \tag{12.2}$$

где амплитуда убывает по экспоненциальному закону. Мерой скорости затухания служит **логарифмический декремент** $\Theta$ — логарифм отношения двух последовательных амплитуд:

$$\Theta = \ln \frac{x(t)}{x(t + T)} = \beta T, \qquad Q = \frac{\pi}{\Theta} = \frac{\omega_0}{2\beta}, \tag{12.3}$$

где $Q$ — *добротность* осциллятора (quality factor). При увеличении $\beta$ частота $\omega$ уменьшается, и при $\beta = \omega_0$ колебательный режим сменяется апериодическим (рисунок 12.2).
