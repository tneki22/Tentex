# UI-кит Tentex

Перенесён из virtex на этапе 0. Прежде чем писать компонент — посмотри, нет ли его здесь. Живая витрина всех компонентов: `/ui-kit` в приложении, исходник `frontend/src/screens/UiKit.tsx`.

Импорт из `frontend/src/components/ui`:

| Компонент | Зачем |
| --- | --- |
| `Button` | `variant`: `primary` · `secondary` · `ghost` |
| `IconButton` | Квадратная кнопка с иконкой, обязательный `label`. `aria-pressed` даёт нажатое состояние |
| `StatusBadge` | Метка статуса, `tone`: `neutral` · `success` · `warning` · `danger` · `info` |
| `SegmentedTabs` | Вкладки с бегущим индикатором и клавиатурой (стрелки, Home, End) |
| `AnimatedDisclosure` | Раскрывашка, управляемая и неуправляемая |
| `EmptyState` · `LoadingState` · `ErrorState` | Три состояния экрана |
| `Popover` | Всплывающая поверхность |
| `Drawer` | Выдвижная панель, `side`: `left` · `right` |

## Стили

Все стили — обычный CSS, никакого Tailwind и CSS-in-JS. Четыре файла в `frontend/src/styles`:

- `tokens.css` — палитра и ритм. Единственное место, где вообще задаются цвета
- `base.css` — сброс, типографика, поля ввода, keyframes
- `ui-kit.css` — по блоку на компонент кита
- `layout.css` — оболочка приложения и заглушки

**Цвет пишется только через токен.** `var(--accent)`, а не `#8a302f`. Полупрозрачные оттенки — через `color-mix(in srgb, var(--accent) 8%, transparent)` или готовые `--accent-wash`, `--accent-edge`.

Основные токены: `--canvas` `--paper` `--paper-strong` (поверхности) · `--ink` `--muted` (текст) · `--line` `--line-strong` (линии) · `--accent` `--accent-dark` `--on-accent` `--navy` `--sage` · `--tone-success` `--tone-warning` `--tone-danger` `--tone-info` · `--shadow` `--focus-ring` · движение `--motion-fast` `--motion-base` `--motion-slow` `--ease` · шрифты `--font-sans` `--font-serif` `--font-mono`.

## Темы

Обе темы описаны одним набором токенов через `light-dark()`. Тему переключает атрибут `data-theme` на `<html>`, который меняет `color-scheme`:

- нет атрибута — как в системе
- `light` / `dark` — зафиксирована

Отсюда два правила:

1. Новый цвет добавляется **один раз** в `tokens.css` в виде `light-dark(светлый, тёмный)`. Отдельного блока для тёмной темы в проекте нет и заводить его не надо.
2. При смене темы на `<html>` на один кадр вешается класс `is-theme-switching`, который гасит все переходы. Без него Chrome не доводит до конца `transition`, вызванный сменой `color-scheme`, и элементы застревают на цветах старой темы. Если добавляешь анимацию цвета — она попадёт под это правило автоматически.

## Правила

- Прежде чем писать компонент — проверь витрину `/ui-kit`.
- Новый компонент общего назначения кладётся в `components/ui` и добавляется в `index.ts` и в витрину.
- Компонент, нужный одному экрану, живёт рядом с экраном, а не в ките.
- Иконки — `lucide-react`, размер 15–16 для интерфейса.
- Кириллица: засечковый шрифт — Literata. Newsreader из virtex не перенесён, у него нет кириллицы.
