# Дизайн-система Tentex

Полное описание — **`DESIGN.md` в корне**. Живая витрина — `/ui-kit` в приложении, исходник `frontend/src/screens/UiKit.tsx`. Прежде чем писать компонент, посмотри там: скорее всего он есть.

Этот файл — короткая шпаргалка на каждый день.

## Три слоя

| Слой | Где | Что знает |
| --- | --- | --- |
| Значения | `styles/tokens.css` | Ничего |
| Примитивы | `components/ui` | Как ведёт себя кнопка, всплывашка, поле |
| Доменные виджеты | `components/domain` | Что такое тема, привязка, качество страницы, стоимость вызова |

**Знает слово из словаря проекта — значит доменный.** Нужен одному экрану — живёт рядом с экраном, а не в системе.

## Примитивы

Импорт из `frontend/src/components/ui`:

`Button`  `IconButton`  `Card`  `StatusBadge`  `SegmentedTabs`  `Popover`  `Dialog`  `ConfirmDialog`  `Tooltip`  `Disclosure`  `Switch`  `Checkbox`  `RadioCards`  `Progress`  `Field`  `Menu`  `PageHead`  `Kbd`  `EmptyState`  `LoadingState`  `ErrorState`

Поведение всплывашек, диалогов, тумблеров, радиогрупп и раскрытий — **Radix Primitives** (пакет `radix-ui`). Фокус, Esc, позиционирование и ARIA написаны там; наше — только вид через токены. Своими руками это не переписывается: см. `DESIGN.md`, раздел про Radix.

Хук: `useTheme` — `system`  `light`  `dark`.

## Доменные виджеты

Импорт из `frontend/src/components/domain`. Каждый держит требование — обойти их «просто текстом» нельзя:

| Виджет | Держит |
| --- | --- |
| `MetricList` | FR-P3: метрика с `value: null` не показывается и **не подменяется нулём** |
| `StepChip` | Один текст следующего шага на все поверхности. «На сегодня всё» — не кнопка |
| `TopicStatusBadge` | Пять статусов темы, тон закреплён. «Нет материала» нейтрален |
| `QualityBadge` | `native`  `ocr`  `ocr_low` — текст с плохой страницы не выдаётся за достоверный |
| `SourceChip` | FR-G23. Окрашен только «источника нет» |
| `MachineMark` | Машинное помечено, несёт источник, отменяется одним нажатием |
| `CostEstimate` | FR-M4/FR-I10: оценка до запуска, дата цен обязательна |
| `OfflineNotice` | FR-I2 нейтрально, FR-I13 warning — не `ErrorState` на весь экран |
| `TaskRow` | Счётчик «сделано из всего» = чекпоинт FR-M14 |
| `ProjectChip`  `GoalLevelPicker` | Знак проекта  четыре уровня цели с пояснением |

## Цвет закреплён за смыслом

`--accent` — действие и выбор  `--tone-success` — подтверждено  `--tone-warning` — верь осторожно  `--tone-danger` — необратимое и упавшее  `--tone-info` — привязано  `--project-color-1…8` — знак проекта.

Два запрета, оба из FR-D17:

- **метрика не красится никогда** — ни зелёным за высокую, ни красным за низкую;
- **полоса прогресса — только у работы** с известным концом (разбор, проход), не у метрики.

## Пять принципов

1. Нейтральная холодная база, один насыщенный акцент.
2. Поверхности скруглены и лежат слоями: `--canvas` → `--paper` → `--paper-strong`.
3. Кегль от 12 до 36, без микрокапса. Основной текст 15px.
4. У всего нажимаемого четыре состояния: покой, наведение, нажатие, фокус.
5. Размеры из шкалы: `--space-*`, `--text-*`, `--radius-*`, `--z-*`. Число на глаз не появляется.

Ориентир — Brilliant и LeetCode: плотный интерфейс с данными, спокойный фон, цвет по делу.

## Стили

Обычный CSS, пять файлов в `frontend/src/styles`, порядок в `main.tsx` значим: `tokens` → `base` → `ui-kit` → `domain` → `layout`.

Значение — только через токен: `var(--accent)`, а не `#2d4edb`. Полупрозрачное — `color-mix(in srgb, var(--accent) 10%, transparent)` или `--accent-wash`.

Темы — одним набором через `light-dark()`. Три правила (почему нельзя завернуть тень, зачем `is-theme-switching`) — в `DESIGN.md`.

## Чего пока нет

Лежит в `virtex/` (только чтение), приедет, когда конкретный экран потребует. Возвращая — перекрась под наши токены:

| Что | Кому понадобится |
| --- | --- |
| `MarkdownMessage`, `ProgressiveMarkdown` (+ `react-markdown`, `remark-gfm`) | Среда темы, разбор ответа |
| `AutoResizeTextarea` | Свободный ответ, конспект |
| Общий `PanelResizeHandle` + `usePanelLayout` | Пока не выносить: рабочая область проекта использует экранный вариант; обобщить после второго потребителя |
| `useVoiceInput` | Устный ответ, этап 10 |
| `Drawer` | Только если мобильный режим выйдет за «не разваливается» |

`Toast` не введён сознательно: фоновые задачи показывает виджет «Фон».

## Правила

- Прежде чем писать компонент — посмотри витрину `/ui-kit`.
- Новый примитив кладётся в `components/ui`, добавляется в `index.ts` **и в витрину**. Не показан — значит им не воспользуются.
- Новый доменный виджет — так же, но в `components/domain`.
- Иконки — `lucide-react`, размер 15–16 для интерфейса.
- Шапка экрана — компонент `PageHead`, не свой `<header>`.
- `transition` — по конкретным свойствам, не `all`.
