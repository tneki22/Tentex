# Tentex

Локальный тренажёр подготовки к экзамену. Курсовая по ТРПС, МГТУ им. Баумана.

Загружаешь учебные материалы, получаешь программу курса, и система показывает **покрытие в обе стороны**: чего у тебя нет по программе и что из материала ты собирался пропустить. Дальше — занятия по темам с проверкой ответов и интервальными повторениями.

Работает офлайн. Внешние модели опциональны и выключаются целиком.

## Запуск

Нужны Node 22+ и Python 3.13+.

```bash
npm install && cd frontend && npm install && cd ../backend && pip install -r requirements-dev.txt
```

Дальше из корня:

```bash
npm run dev
```

Фронтенд — http://localhost:5173, API — http://localhost:8000, документация API — http://localhost:8000/docs.

Либо в контейнерах:

```bash
docker compose up
```

## Проверка

```bash
npm run typecheck && npm run build
cd backend && python -m pytest
```

Фронтенд проверяется сборкой: тестового набора и команды `npm test` на нём нет. На бэкенде — pytest (313 тестов на 03.09.2026) и `python -m ruff check .`.

Сквозные проверки по подсистемам лежат в `backend/scripts/`: `check_stage2` … `check_stage5`, `check_manual_binding`, `check_ai_gateway`, `check_exam_chat`, `check_library_workspace`. Они поднимают чистые базы, переживают перезапуски и проверяют жизненный цикл черновика, импорт и редактирование Программы, undo, конвейер материалов, привязки, шлюз моделей и чат.

Уровень логов — переменная `TENTEX_LOG_LEVEL` (по умолчанию `INFO`).

Фактические контракты реализованных подсистем — в `docs/architecture/`, индекс там же в `README.md`.
