# Tentex

Локальный тренажёр подготовки к экзамену. Курсовая по ТРПС, МГТУ им. Баумана.

Загружаешь учебные материалы, получаешь программу курса, и система показывает **покрытие в обе стороны**: чего у тебя нет по программе и что из материала ты собирался пропустить. Дальше — занятия по темам с проверкой ответов и интервальными повторениями.

Работает офлайн. Внешние модели опциональны и выключаются целиком.

## Запуск

Нужны Node 22+ и Python 3.13+.

```bash
npm install && cd frontend && npm install && cd ../backend && pip install -r requirements-dev.txt
```

Дальше из корня:

```bash
npm run dev
```

Фронтенд — http://localhost:5173, API — http://localhost:8000, документация API — http://localhost:8000/docs.

Либо в контейнерах:

```bash
docker compose up
```

## Проверка

```bash
npm run typecheck && npm run build
python backend/scripts/check_stage2.py
python backend/scripts/check_stage3.py
```

Сквозные проверки этапов 2 и 3 поднимают чистые базы, переживают перезапуски и проверяют жизненный цикл черновика, импорт и редактирование Программы, undo, проекты и раскладку Рабочей области. Точечные тесты — `python -m pytest` в `backend/`.

Уровень логов — переменная `TENTEX_LOG_LEVEL` (по умолчанию `INFO`).

## Что где

| Каталог | Что |
| --- | --- |
| `backend/` | FastAPI |
| `frontend/` | Vite + React + TypeScript |
| `data/` | SQLite и файловое хранилище. В git не едет |
| `.agents/skills/` | Проектные скиллы для агентов |
| `virtex/` | Прошлый проект, откуда взят UI-кит. Справочник, в git не едет |

Документы проекта: `BRIEF.md` — о продукте, `REQUIREMENTS.md` — требования, `PLAN.md` — план работ, `AGENTS.md` — правила для агентов, `docs/architecture/stage-2-core.md` — ядро данных, `docs/architecture/stage-3-live-projects.md` — живые проекты и контракт Программы, `docs/architecture/stage-4-reference-answers.md` — эталоны и полный офлайновый экзаменационный путь.

## Состояние

Этап 4 завершён: экзаменационная ветка проходит от мастера до чтения эталона без интернета и моделей; ответы связаны со стабильными узлами Программы, импортируются из текста, редактируются в Карте эталонов и отображаются в Рабочей области. Проекты удаляются полностью. Следующий шаг — этап 5: загрузка и возобновляемый разбор материалов.
