# Добавление фонов

Фоны добавляются в код и попадают в приложение после сборки. Импорт исполняемого TSX через настройки не реализован.

1. Передай агенту TSX-файл, доступ к Tentex и промпт ниже (он также копируется из Параметров).
2. Агент переносит только декоративный эффект в React-компонент, регистрирует его в `BACKGROUNDS` и проверяет приложение.
3. Новый вариант автоматически появляется в списке пресетов; его id хранится вместе с настройками.

Пример записи в `frontend/src/app/Background.tsx`:

```tsx
{ id: "floating-paths", label: "Плавающие линии", component: FloatingPaths },
```

Компонент без аргументов используется в общем слое и в статичном превью. CSS-анимации по умолчанию приостановлены, запускаются только внутри `.background-art[data-motion="true"]`, а media query уменьшения движения снова ставит их на паузу. Цвета — токены, прозрачность — на общем слое.

«Плавающие линии» сохраняют геометрию исходного SVG. «Частицы» сохраняют ASCII-узлы, связи и восходящие лучи, с фиксированной раскладкой и спокойным CSS-движением вместо canvas и реакции на мышь из демо. Исходники пользователя не изменены.

## Промпт

```text
Добавь приложенный TSX как новый пресет заднего фона Tentex.
Изучи frontend/src/app/Background.tsx, BackgroundPresets.tsx и frontend/src/styles/background.css.
Сохрани рисунок исходного эффекта, убери демостраницу, тексты, кнопки и внешние загрузки.
Сделай декоративный React-компонент без аргументов; добавь { id, label, component } в BACKGROUNDS.
Общий слой уже задаёт прозрачность и покрывает весь экран. Используй цвета из tokens.css.
SVG/CSS предпочтительны; анимации должны останавливаться при data-motion=false и prefers-reduced-motion: reduce.
Превью в background-swatch должно быть статичным. Для canvas освобождай ресурсы, останавливай requestAnimationFrame в скрытой вкладке и при выключенном движении; учитывай тему и resize.
Не выполняй загруженный код в браузере и не добавляй зависимости без необходимости.
Проверь выбор, превью, сохранение, обе темы и остановку движения; обнови SCREENS.md, выполни typecheck, build и тест frontend/background.spec.ts.
```
