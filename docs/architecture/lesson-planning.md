# Планирование занятий — фактический контракт

Учебниковый проект и «Свободное изучение» используют один `workspace_variant=textbook`.
Раздел включается через `lesson_planning` в `Project.enabled_modules`; старый ключ
`plan` учебниковых проектов не включает его. В настройках это единственный
переключаемый модуль. Выключение сохраняет календарь и факты времени.

## План

`GET /api/projects/{id}/lesson-planning` возвращает ревизию, дату учебных суток,
дедлайн, ритм, список уроков, назначения, недоступные назначения, уроки без даты,
расчётное окончание и время сегодня по урокам. `POST .../preview` с
`mode=append|rebuild_future` создаёт предпросмотр без записи. `PUT .../plan`
принимает `{expected_revision, items}` и заменяет список атомарно; при устаревшей
ревизии — 409 `lesson_plan_stale`.

Назначение: `id, lesson_id, title, on_date, minutes, origin`. Хранилище —
существующая `preparation_plans` с отдельной строкой проекта. Один урок может
иметь несколько тем, но только одну дату. При распределении допускается готовый
`ready` урок с содержательным блоком и действующей темой программы. Черновики,
пустые и архивные уроки видны в списке, но не распределяются. Ручные назначения,
прошедшие дни и завершённые уроки не перестраиваются. При изменении программы
недоступное назначение остаётся видимым до явного исправления.

Длительность — `Lesson.duration_minutes`, затем `GoalPassport.session_minutes`,
затем 30 минут. Бюджет — `minutes_per_day` либо 60, учебные дни — первые
`days_per_week` дней недели либо понедельник–пятница. Дедлайн включён в диапазон
распределения; без него предел — 730 дней. Урок длиннее дневного бюджета ставится
один на день. «Расчёт по плану» продолжает распределение за дедлайн и не
оценивает знания.

## Время

`POST .../time` принимает не более 200 интервалов с `id, session_id, lesson_id,
started_at, ended_at`, каждый не длиннее пяти минут; ответ содержит
`accepted_ids, ignored_ids`. Идентификатор делает повторную доставку безопасной.
`StudyInterval` хранит `lesson_id` и снимок названия без FK на удаляемый урок,
поэтому название и время остаются после его удаления.

Клиент использует общий таймер экзамена: активная видимая вкладка, глобальная
браузерная блокировка от двойного счёта, пауза через пять минут бездействия,
IndexedDB-буфер и отправка каждые 30 секунд. Он работает только при включённом
разделе и открытой вкладке готового непустого урока в Рабочей области. Отдельного
«Начать день» нет. Учебные сутки начинаются в 04:00 по времени настроек
подготовки (по умолчанию Europe/Moscow). При выключении сервер обрезает поздно
доставленный интервал моментом выключения. Отметка «Урок пройден» — отдельный
`StudyActivity` с нулевым временем; она не влияет на интервалы.
