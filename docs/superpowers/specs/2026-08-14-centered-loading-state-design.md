# Центрированное состояние загрузки

## Цель

Убрать у состояний ожидания эффект маленькой карточки в левом верхнем углу и дать единый, спокойный визуальный ориентир на время чтения данных.

## Решение

`LoadingState` остаётся единственным примитивом загрузки. Он получает вариант размещения:

- `page` — для загрузки целого экрана: группа выровнена по центру доступной рабочей области; без рамки и карточки;
- `section` — для загрузки внутри панели, вкладки или диалога: та же группа выровнена по центру контейнера, с меньшей минимальной высотой.

Полный экран использует `page` во всех существующих ранних возвратах `if (loading)`. Вложенные запросы используют `section`; компактная загрузка не меняет геометрию соседних данных после их появления.

## Внешний вид и движение

Состояние состоит из тонкого кольцевого индикатора, заголовка из текущей подписи и необязательной спокойной вторичной строки. Кольцо не сообщает процент и не выглядит как прогресс измеримой работы: это неопределённое ожидание. Акцентный сегмент вращается ровно и отключается при `prefers-reduced-motion`.

Контент появляется кратким `opacity`/`translateY` переходом. Загрузка не использует рамку, тень, статусный цвет или фальшивую полосу прогресса.

## Совместимость и проверка

Публичная подпись `label` сохраняется: существующие 17 вызовов не требуют изменения текста. В компонент добавляется только явный вариант размещения с безопасным значением по умолчанию. После изменения проверяются типы, production-сборка и живой вид полной и локальной загрузки в браузере после перезапуска `web`.
