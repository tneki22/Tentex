# Доведение «Моей подготовки»

**Цель:** рабочие распределение, долг и начало дня; понятные бюджет, графики и события.
**Архитектура:** существующие черновики → применение → undo, факты отдельно от плана. Расчёты бюджета и событий на сервере, UI использует OpenAPI-типы.
**Стек:** FastAPI, SQLAlchemy, React, Radix, CSS на токенах.
