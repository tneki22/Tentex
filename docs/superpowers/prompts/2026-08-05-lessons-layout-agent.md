## Главное разделение

- В **Рабочей области** пользователь изучает Тему. Там Урок открывается вкладкой рядом с Источником.
- В разделе **«Уроки»** пользователь создаёт и редактирует Уроки — по одной Теме, выбранным Темам или по порядку всей Программы.
- Не делай экран «Уроки» библиотекой для чтения. Чтение и изучение находятся в Рабочей области.

## Что нужно получить

### 1. Рабочая область

Для проекта `vector-indexes`:

- в нижней проектной навигации есть активная ссылка `Уроки`;
- в меню вкладок учебной конфигурации есть `Урок`;
- Источник и Урок можно открыть одновременно в соседних колонках;
- для Темы `ivfflat` доступны два Урока и selector между ними;
- для `hybrid-search` показано пустое состояние `Для этой темы ещё нет урока`;
- `Создать урок` ведёт на `/projects/vector-indexes/lessons?topic=hybrid-search`;
- `Редактировать` ведёт на `/projects/vector-indexes/lessons?topic=ivfflat&lesson=ivf-structure`;
- переход обратно вида `/projects/vector-indexes?topic=ivfflat&tab=lesson&lesson=ivf-structure` открывает Источник в первой колонке и Урок во второй;
- выбранный Урок сохраняется отдельно для каждой Темы.

Для проекта `demo` Уроки скрыты, потому что `lessonsEnabled: false`.

### 2. Раздел «Уроки»

Маршрут только один:

```text
/projects/:projectId/lessons
```

Query-параметры:

```text
?topic=:topicId&lesson=:lessonId
```

Не создавай `/lessons/new` и `/lessons/:lessonId/edit`.

Экран полнооконный:

- слева дерево Программы с поиском, checkboxes и количеством Уроков;
- в центре section overview, single-topic editor или batch table;
- справа inspector выбранного блока;
- снизу слева проектная навигация, где `Уроки` активны.

### 3. Дерево

- Шеврон раскрывает раздел.
- Клик по названию выбирает узел.
- Checkbox Темы добавляет её в массовый выбор.
- Checkbox раздела выбирает все изучаемые дочерние узлы.
- При двух и более выбранных Темах центр переключается в batch mode.
- Строка Темы показывает ровно одно: `нет урока`, `1 черновик`, `1 урок`, `2 урока`.
- Поиск `Найти тему или урок` ищет и по названиям Тем, и по названиям Уроков, сохраняя родителей совпадения.
- Не добавляй фильтры.

### 4. Одиночный режим

Для одной Темы:

- сверху её название и краткое состояние источников;
- затем список её Уроков;
- при выборе Урока открывается editor;
- если Уроков нет — `EmptyState` с `Создать вручную` и `Собрать с ИИ`.

Editor — красивый прототип, не настоящий rich-text движок:

- toolbar: название, цель, статус, `Сохранено`, `Открыть в Рабочей области`, `Готов`;
- canvas из типизированных блоков;
- выбранный блок подсвечен;
- действия `Вверх`, `Вниз`, `Дублировать`, `Удалить` работают локально;
- удаление подтверждается `ConfirmDialog`;
- меню добавляет `Текст`, `Определение`, `Изображение`, `Диаграмма`, `SQL-задача`;
- inspector показывает тип, layout preset, источники;
- действия ИИ в inspector видимы, но disabled.

Не реализуй drag-and-drop, contenteditable, историю версий, undo/redo и форматирование текста.

### 5. Документ Урока

Создай общий renderer и используй его:

- в Рабочей области с `mode="study"`;
- в editor с `mode="editor"`.

Обязательные блоки demo:

- несколько абзацев текста;
- callout/определение;
- источник с номером страницы;
- источник с `ocr_low` и `QualityBadge`;
- изображение-placeholder с alt и подписью;
- статический preview диаграммы без Mermaid;
- строка из двух колонок;
- SQL-задача на всю ширину с disabled `Запустить` и `Проверить`.

Блок `model-knowledge` подписывается `Знания модели · без источника`. Потерянный источник подписывается `Источник недоступен`, но блок не исчезает.

### 6. Создание вручную

`Создать вручную` создаёт локальный черновик:

```text
Новый урок: <название Темы>
```

В нём один раздел, одна flow-строка и один текстовый блок с подсказкой. Черновик сразу открывается в editor.

### 7. Mock-ИИ

`Собрать с ИИ` открывает `Dialog` из двух шагов.

Шаг 1:

- выбранные Темы;
- цель;
- сложность;
- длительность;
- основание: источники проекта / смешанное / знания модели;
- checkboxes активностей и медиа.

Шаг 2:

- три раздела storyboard;
- цели;
- типы блоков;
- layout presets;
- `CostEstimate`.

`Собрать черновик` не вызывает модель. Он копирует готовый demo-Урок и показывает status message:

```text
Прототип: модель не вызывалась
```

Если модели выключены, внутри dialog показывается `OfflineNotice`, подтверждение disabled, ручное создание продолжает работать.

### 8. Массовый режим

Должны работать:

- `Выбрать темы без уроков` для текущего раздела;
- `Создавать по порядку` для всей Программы;
- исключение отдельной строки;
- action каждой строки: `вручную / с ИИ / пропустить`;
- переопределение длительности;
- `Подготовить черновики`.

Не перезаписывай существующие Уроки. Результат локальный:

- manual → пустой черновик;
- ai → копия demo с меткой прототипа;
- skip → без изменений.

После подготовки строка показывает `Черновик готов` и позволяет открыть его в single mode.
