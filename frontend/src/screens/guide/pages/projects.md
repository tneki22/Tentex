**Проект** — главный объект Tentex. Всё, чем вы занимаетесь, происходит внутри проекта: там лежат программа, привязки материалов, уроки, конспекты и прогресс. Эта страница объясняет, что именно внутри, что общее для всех проектов, как проект хранится и как его перенести на другой компьютер.

## Что такое проект {#what}

Проект — это *одна учебная цель*: экзамен, курс, книга или тема, которую вы хотите разобрать. У него свои настройки, своя программа и свой прогресс. Проектов можно завести сколько угодно; они не влияют друг на друга.

На экране `Проекты` каждый проект — карточка со знаком и цветом, названием, типом в углу (`Э` — экзамен, `Уч` — учебник, `СИ` — свободное изучение) и крупным отсчётом: сколько дней до экзамена или сколько тем в программе. Кнопка `Продолжить` открывает рабочую область проекта, меню `⋯` — переставить, архивировать или удалить. Порядок карточек меняется перетаскиванием.

:::tip Один предмет — два подхода, два проекта
Готовитесь к экзамену по базам данных и заодно хотите разобраться в теме по учебнику? Заведите **два проекта**: «БД — экзамен» с вопросами и ответами и «БД — разбираюсь» с учебником. Переключать подход внутри одного проекта нельзя — так программа и покрытие каждого остаются понятными.
:::

## Что внутри проекта {#inside}

Схема ниже показывает главное различие: одни вещи *общие для всей установки*, другие *принадлежат проекту*.

:::diagram structure
Материалы лежат в общей Библиотеке и подключаются к проектам. Всё остальное — программа, привязки, занятия и прогресс — у каждого проекта своё.
:::

| Общее для установки | Принадлежит проекту |
| --- | --- |
| Файлы материалов и результат их разбора: текст страниц, блоки | Паспорт цели и настройки проекта |
| Индексы поиска | Программа: разделы, темы, подпункты |
| Провайдеры, ключи, модели | Роль каждого материала в этом проекте и ваши пояснения к нему |
| Резервные копии, оформление, фоновые задачи | Привязки «тема — фрагмент» и покрытие |
| | Уроки, конспекты, карточки |
| | Ваши ответы, попытки и прогресс, план подготовки, чаты |

Из этого следует несколько практических вещей:

- **Материал разбирается один раз.** Тот же учебник в двух проектах не обрабатывается заново и не занимает места дважды.
- **Роль материала своя в каждом проекте.** В одном проекте книга «основная», в другом — «справочная».
- **Удаление проекта не удаляет материалы.** Они остаются в Библиотеке и доступны другим проектам.
- **Проект может быть без материалов.** Это нормальное состояние: программа есть, материалы добавите позже.

### Разделы проекта

Слева в проекте стоит список разделов. Набор зависит от режима и включённых модулей:

| Раздел | Что там | Режим |
| --- | --- | --- |
| `Материалы` | материалы проекта, их роли и состояние подготовки | все |
| `Программа` или `Вопросы экзамена` | дерево того, что нужно освоить | все |
| `Ответы` | эталонные ответы к вопросам экзамена | экзамен |
| `Уроки` | сценарии изучения тем | все |
| `Покрытие` | чем подтверждена программа и что осталось без темы | учебник, свободное |
| `Моя подготовка` | календарный план до даты экзамена | экзамен |
| `Планирование занятий` | расписание и расчёт окончания по сроку | учебник, свободное (включается в настройках) |
| `Карточки` | карточки для повторения | экзамен |
| `Настройки` | название, цвет, срок, паспорт цели | все |

:::info Учебник и свободное изучение
Эти два режима работают в одной и той же учебниковой среде: разделы, привязки и покрытие у них общие. Различаются они мастером создания: у свободного изучения он начинается с цели, а не с источника.
:::

## Жизнь проекта {#life}

| Состояние | Что это |
| --- | --- |
| **Черновик** | Мастер создания сохраняет проект, пока вы не закончили. Среди активных проектов он не показывается. |
| **Активный** | Обычный рабочий проект: карточка на экране `Проекты`. |
| **В архиве** | Проект убран из сетки, но всё в нём сохранено. Лежит в блоке `Архив и завершённые` внизу, кнопка `Вернуть в работу` возвращает его. Архивный проект не участвует в повторениях и напоминаниях. |
| **Завершён** | Тоже лежит в блоке архива; вернуть такой проект в работу нельзя. |

Архивировать проект — меню `⋯` на карточке → `Архивировать`. Проект остаётся в базе, ничего не теряется.

:::danger Удалить навсегда — это необратимо
Пункт `⋯ → Удалить навсегда` стирает паспорт цели, программу, рабочую раскладку и все ответы проекта. Отменить нельзя. Общие файлы Библиотеки остаются на месте. Если сомневаетесь — **архивируйте**.
:::

### Настройки проекта

В разделе `Настройки` проекта правятся название, описание, знак, один из восьми цветов, срок (дедлайн) и паспорт цели: предмет, назначение, уровни, формат и учебный ритм. Все изменения сохраняются одной кнопкой.

:::warning Паспорт цели не перестраивает программу
Если вы поменяли цель или охват, уже готовая программа сама не изменится. Паспорт влияет на новые подсказки ИИ, а не переписывает то, что построено.
:::

Не путайте настройки проекта и `Параметры установки`: ключи провайдеров, модели, копии и хранилище относятся ко всей установке и в проекте не редактируются.

## Импорт, экспорт и перенос {#transfer}

Данные принадлежат вам, поэтому вынести их можно двумя способами. Они разные по смыслу, и перепутать их стоит дороже всего в этом разделе.

:::diagram transfer
Пакет проекта добавляет один проект рядом с остальными. Резервная копия переносит установку целиком и при восстановлении заменяет её.
:::

### Пакет проекта

Файл `.tentex-project` содержит один проект. Экспорт находится в `Параметры → Хранилище → Перенос проектов`: выберите проект, состав пакета и нажмите `Экспортировать проект`. Готовый пакет доступен для скачивания 24 часа.

Состав пакета выбирается из двух профилей:

| Профиль | Кому и для чего | Что попадает |
| --- | --- | --- |
| **Поделиться** | отдать проект другому человеку или сделать чистую заготовку | учебное содержание без личного: без ответов, оценок, активности, чатов и личного прогресса |
| **Для себя** | продолжить тот же проект на другом компьютере | то же и личное: прогресс, история и рабочее состояние |

В любом профиле в пакет входят файлы материалов и результаты их разбора: текст страниц, блоки и привязки к программе.

**Импорт** пакета запускается кнопкой `Импортировать проект` на первом экране мастера создания либо в `Параметры → Хранилище → Перенос проектов`. Сначала Tentex проверяет файл и показывает, что в нём лежит. Дальше правила простые:

- импорт **всегда создаёт новый проект**: ни один из существующих не меняется и не затирается;
- у импортированного проекта новые внутренние идентификаторы, а материалы, которые в установке уже есть (совпал файл), повторно не хранятся;
- если пакет уже импортировали раньше, Tentex предупредит и создаст ещё одну копию;
- сама работа идёт в фоне, ход виден в панели `Фоновые задачи`.

:::info Смысловой поиск после импорта
Смысловой индекс в пакет не входит. Сразу после импорта поиск работает по словам. Если у вас установлена совместимая модель эмбеддингов, материалы проиндексируются в фоне сами; иначе смысловой поиск включится, когда вы поставите модель.
:::

### Резервная копия

Файл `.tentex-backup` — это вся установка: все проекты, Библиотека, исходные и обработанные файлы, индексы. Копию делают для страховки и для переезда на новый компьютер целиком.

:::warning Восстановление заменяет всё
Восстановление из копии *заменяет* текущие проекты, Библиотеку и файлы. Перед этим Tentex сам делает страховочную копию и ждёт, пока закончатся идущие задачи, но подтверждайте действие только когда уверены.
:::

В копию **никогда не попадают** ключи API, локальные модели и служебный секрет установки. После переноса на другой компьютер ключи придётся ввести заново, а модели эмбеддингов и распознавания — скачать. Автоматические копии по умолчанию выключены: включить их можно в `Параметры → Хранилище → Резервные копии`.

### Что выбрать

| Задача | Способ |
| --- | --- |
| Отдать проект другому человеку | пакет проекта, профиль `Поделиться` |
| Продолжить один проект на другом компьютере | пакет проекта, профиль `Для себя` |
| Перенести всё на новый компьютер | резервная копия |
| Страховка от сбоя и ошибок | резервная копия, лучше с включённым расписанием |
| Сделать заготовку из готового проекта | пакет проекта, профиль `Поделиться`, затем импорт |
