С материалами в Tentex можно работать в двух местах, и это не два разных хранилища. **Библиотека** хранит сами файлы и их текст. **Материалы** внутри проекта показывают, какие из этих файлов подключены к проекту и в какой роли. Файл один, а работают с ним из обоих экранов.

## Два места, один файл {#two}

| | Библиотека | Материалы проекта |
| --- | --- | --- |
| **Где открыть** | `Библиотека` в левой панели | раздел `Материалы` внутри проекта |
| **О чём** | файл как таковой: хранение, подготовка текста, версии | как проект использует файл: роль, привязки к темам |
| **Что видно** | все файлы установки, любых проектов | только файлы этого проекта |
| **Что можно сделать** | добавить, подготовить, проверить, сравнить версии, удалить файл целиком | добавить, подключить из Библиотеки, сменить роль, привязать к вопросам, найти в интернете |
| **Удаление** | удаляет файл из всех проектов | отключает файл только от этого проекта |

:::info Подготовка одна на всех
Если один и тот же файл подключён к двум проектам, текст готовится один раз, а исправления в нём видны сразу в обоих. Перед повторной подготовкой панель предупредит, сколько проектов затронет новая версия.
:::

## Экран Библиотеки {#screen}

Наверху три вещи: поле поиска, кнопка `Поиск` с глобусом (поиск материалов в интернете, ему посвящена страница «Поиск в интернете») и главная кнопка `Добавить материал`. Под ними две вкладки:

- `По названиям` находит файл по имени, предмету и другим полям карточки;
- `По содержимому` ищет слова внутри уже подготовленных материалов и показывает, на каких страницах они встречаются.

Дальше идёт сводка (сколько файлов, страниц и мегабайт) и фильтры: по названию, предмету, виду, состоянию и качеству текста, сортировка. Файлы можно отметить флажками. Тогда над списком появляется панель: `Поставить в обработку (N)` запускает **быструю подготовку текста** сразу для всех выбранных, которым она ещё нужна, а `Удалить` убирает выбранные файлы.

В строке каждого файла видны:

| Что | Значение |
| --- | --- |
| Размер, число страниц, число блоков | «блоков» появляется, когда текст подготовлен |
| `Не подготовлен` | файл загружен, но текст ещё не готовился: нажмите `Подготовить материал` |
| `Распознано: N` | у материала есть N страниц, прочитанных распознаванием, а не взятых из файла |
| `Нет индекса` | материал ещё не добавлен в поисковый индекс по смыслу (это настраивается в разделе «Настройка поиска») |
| Названия проектов | где файл используется; `не используется`, если ни в одном |

## Экран материала {#viewer}

Клик по файлу открывает его на весь экран. Здесь три зоны, и у каждой свои вкладки:

:::terms info
[Eye] Режим просмотра (сверху)
`Оригинал` показывает страницы файла, `Текст` показывает то, что получилось после подготовки, `Сравнение` ставит их рядом. Сравнение нужно, чтобы проверять распознавание.

[ListTree] Левая панель
`Оглавление` — структура документа со страницами, `Страницы` — плитка страниц с отметками, где распознавание могло ошибиться. Панель открывается и закрывается кнопкой в верхней полосе.

[Settings] Правая панель
`Обработка` запускает подготовку текста и выбирает режим, `Версии` хранит прежние результаты и сравнивает их, `Файл` показывает, где файл используется, и удаляет его. В проекте вместо версий появляются `Привязки`.
:::

## Материалы внутри проекта {#in-project}

В проекте список материалов показывает для каждого файла роль, число страниц, режим подготовки, сколько тем ссылается на файл и состояние. Слева тот же список сгруппирован по ролям.

Три главные кнопки в шапке:

- `Добавить материал`: новый файл сразу в этот проект;
- `Из Библиотеки`: подключить то, что уже загружено, без копирования;
- `Найти в интернете`: раскрывает чат поиска (страница «Поиск в интернете»).

Роль и приоритет меняются в меню по правой кнопке мыши на файле. Роль определяет, как файл используется. Например, *основной* источник задаёт структуру программы, а *справочный* остаётся под рукой.
