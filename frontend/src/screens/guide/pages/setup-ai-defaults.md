**Модель по умолчанию** — та, что выполняет задачу, если вы не назначили другую. Это самая важная страховка в настройке ИИ: одна выбранная модель делает рабочими почти все функции, и вам не нужно настраивать их по очереди.

Моделей по умолчанию две, потому что тексты и голос обрабатываются разными моделями:

:::terms accent
[MessagesSquare] Для текста
Чат, уборка текста, группировка вопросов, проверка ответов, уроки, карточки и всё остальное, что работает с текстом. Подходит любая добавленная модель, которая отвечает текстом.

[Mic] Для речи
Голосовой ввод в чате и расшифровка аудиоматериалов в режиме `Облако`. В списке показываются только модели, которые принимают аудио.
:::

:::info А модель для изображений?
Модель, которая читает картинки страниц, выбирается не здесь, а в `Параметры → Распознавание → Облако`. Там же видно цену страницы и причины, по которым модель не подошла. Подробнее на странице [«Режимы распознавания»](/guide?section=setup-ocr-modes).
:::

## Как выбрать {#pick}

:::steps
1. Откройте `Параметры → ИИ → По умолчанию`.
2. В блоке `Для текста` выберите сначала `Провайдера`, затем `Модель`. В списке только добавленные модели.
3. Нажмите `Сохранить модель для текста`. Выбор **не сохраняется сам**: без нажатия кнопки изменение пропадёт.
4. То же повторите в блоке `Для речи`, если нужен голосовой ввод: кнопка называется `Сохранить модель для речи`.
:::

Если ни одна из добавленных моделей не принимает аудио, в блоке речи появится подсказка. Откройте [`Модели`](/guide?section=setup-ai-models), нажмите карандаш у нужной модели и отметьте `Принимает аудио`. Каталог провайдера не всегда сообщает об этом сам.

Выбранные модели видны в блоке `Обзор` двумя плитками, `Текст` и `Речь`. Клик по плитке ведёт к карточке модели в списке.

:::tip Быстрая смена из левой панели
Модель по умолчанию можно поменять и не заходя в параметры: кнопка `Модели` внизу левой панели раскрывает два списка, `Текст` и `Речь`, а выбор применяется сразу. Удобно, когда нужно быстро переключиться между дешёвой и сильной моделью. Подробнее в [«Состоянии и фоновых задачах»](/guide?section=status-jobs#models).
:::

## Как это работает вместе с функциями {#resolve}

У каждой функции есть три источника модели, и берётся первый найденный:

1. **Выбор в запуске.** Многие функции разрешают выбрать модель прямо там, где они запускаются: в поле чата, в окне сборки урока, в окне исследования покрытия, в панели запуска распознавания.
2. **Своя модель функции.** Её назначают в блоке [`Функции`](/guide?section=setup-ai-functions).
3. **Модель по умолчанию** для нужного вида: текст, речь.

Поэтому есть два надёжных подхода:

- **«Настроил и забыл».** Выберите одну модель по умолчанию и не трогайте функции. Всё заработает. Для тяжёлых задач при запуске всё равно можно выбрать другую модель.
- **«Точечно».** Модель по умолчанию задаёт запасной вариант, а для нескольких функций вы назначаете свои. Изменение по умолчанию потом не затронет функции с собственной моделью.

## Что выбрать по умолчанию {#advice}

Выбирайте модель, которая уверенно отвечает **по схеме** (структурный ответ) и стоит недорого: по умолчанию выполняются десятки мелких задач, а не только «умные». Хороший кандидат — быстрая модель среднего класса. Сильную модель лучше не ставить по умолчанию: она станет дорогой везде, даже на уборке текста.

Для речи берите специализированную модель распознавания речи (Whisper и подобные) у провайдера, который её отдаёт. Многие ИИ-модели общего назначения тоже принимают аудио, но специализированные обычно быстрее и дешевле.

:::tip Смена модели ничего не ломает
Уже готовые результаты (уроки, привязки, программы) не пересчитываются при смене модели по умолчанию. Она влияет только на новые запросы. Модель, которая сейчас выбрана по умолчанию, удалить нельзя: сначала выберите другую.
:::
