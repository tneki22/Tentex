**Модель** — конкретная «нейросеть» у провайдера, которая отвечает на запросы. У OpenRouter их сотни, и показывать все в списках выбора было бы бессмысленно. Поэтому в Tentex устроено так: каталог провайдера остаётся у провайдера, а в приложении живут **только те модели, которые вы добавили сами**. Именно из них вы потом выбираете модель по умолчанию и модели для функций.

## Как добавить модель {#add}

Есть два пути: найти модель в каталоге провайдера (проще и точнее) или добавить по ID вручную.

### Поиск в каталоге

:::steps
1. Откройте `Параметры → ИИ → Модели`. Сверху выберите `Провайдер`.
2. Нажмите `Поиск моделей`. Tentex запросит каталог (это бесплатно).
3. Введите часть названия или ID. Переключатель `Все` / `Добавленные` / `Ещё не добавлены` сузит список. Показываются первые 60 результатов: если не нашлось, уточните запрос.
4. В каждой строке видны контекст, цена входа и выхода за миллион токенов и поддержка рассуждения. Нажмите `Добавить`: модель попадёт в ваш список, а строка станет `Уже добавлена`.
:::

### Вручную

Кнопка `Добавить вручную` нужна, когда провайдер не отдаёт каталог или модели в нём нет: это типично для локальных серверов и части OpenAI-совместимых сервисов.

| Поле | Что вписать |
| --- | --- |
| `ID модели` | точный идентификатор у провайдера, например `vendor/model`. После сохранения изменить его нельзя |
| `Название` | как модель будет называться в списках |
| `Контекст, токенов` | размер контекстного окна. Пусто, если неизвестно |
| `Вход, $ / 1 млн` и `Выход, $ / 1 млн` | цена за миллион токенов из прайса провайдера. Пусто, если неизвестна |
| `Возможности` | флажки, о которых ниже: **самое важное поле** |

:::warning Возможности нужно отметить вручную
Каталог не всегда сообщает, что умеет модель. У модели, добавленной вручную, по умолчанию отмечены только `Принимает текст` и `Отвечает текстом`. Если не отметить остальное, модель не появится там, где нужна: Tentex не станет предлагать то, чего, по его сведениям, она не умеет.
:::

Что отмечать, чтобы модель заработала в нужной роли:

| Для чего модель | Отметьте |
| --- | --- |
| Почти любая текстовая функция (программа, уроки, покрытие, карточки, уборка и др.) | `Принимает текст`, `Отвечает текстом` и **`Структурный ответ (response_format)`**: без последнего модель не попадёт в списки большинства функций |
| Чат | достаточно `Принимает текст` и `Отвечает текстом`: чат идёт потоком и структурного ответа не требует |
| Распознавание страниц и описание изображений | `Принимает изображения` и `Структурный ответ (response_format)`; контекст желательно не меньше 32 000 токенов |
| Голосовой ввод и расшифровка аудио | `Принимает аудио` |
| Полнота описания | `Принимает файлы`: сейчас ни одной функции не требуется, отметка нужна только для точности карточки |

:::tip Если функция пишет «Модель не поддерживает…»
Это значит, что у модели не отмечена нужная возможность (например, `Принимает изображения` для распознавания или `Принимает аудио` для речи). Откройте карандаш `Изменить модель`, отметьте её и сохраните: сообщение подскажет, чего именно не хватает.
:::

:::info Пустые поля — это нормально
Если цена или контекст неизвестны, оставьте поля пустыми. Модель будет работать, но у неё не получится оценить стоимость запроса заранее: для таких запросов Tentex попросит подтверждение, а дневной лимит не сможет их учесть. Данные можно дописать позже, нажав карандаш `Изменить модель`.
:::

## Как читать карточку модели {#card}

У каждой добавленной модели в списке есть строка с фактами:

- `Цена за 1 млн токенов`: отдельно вход (то, что вы отправляете) и выход (то, что отвечает модель). Выход обычно дороже. Токен ≈ часть слова: для русского текста примерно два-три символа, поэтому страница учебника — это порядка тысячи токенов.
- `Контекст`: сколько токенов модель удерживает за один раз. Ниже видно `Ответ до N`: предел длины ответа. Большие задачи (программа целого учебника, проход 2) требуют большого контекста.
- `Рассуждение`: умеет ли модель «думать» перед ответом и на каких уровнях. `нет данных` значит, что каталог об этом не сообщил.
- `Возможности`: метки `Вход: текст`, `Выход: текст`, `response_format` и другие. Две метки на виду, остальные под ссылкой `Ещё N`.

Если провайдер не указал возможности, под карточкой появится пометка «Провайдер не указал все возможности». Это не поломка: пустые данные значат «неизвестно», а не «не умеет». Отметить нужное можно через `Изменить модель`.

Если модель исчезла из актуального каталога провайдера, строка серая с пометкой «Модели нет в актуальном каталоге». Старые записи в журнале остаются читаемыми, но выбрать такую модель нельзя.

## Проверка модели {#test}

Кнопка `Тест` отправляет модели короткий вопрос и показывает результат:

- **время ответа**;
- **токены** входа и выхода (сколько потрачено);
- `Ответила модель`: если провайдер подставил другую модель (так делают «автоматические» роутеры), это будет написано.

Для модели речи вместо вопроса уходит секунда тишины: слов в ней нет, поэтому пустой текст в ответе нормален, важно, что модель приняла аудио. Успешный тест сам дописывает моделью текст (или аудио) в список возможностей, неудачный ничего не меняет.

:::warning Тест не проверяет чтение картинок
Проверка убеждается, что модель отвечает и понимает текст. Читает ли она изображения, `Тест` не выясняет. Для распознавания проверьте модель на одной-двух страницах в Библиотеке (область запуска `Диапазон`), прежде чем запускать весь документ.
:::

Тест обычно обходится в доли цента и попадает в [историю запросов](/guide?section=setup-ai-usage) как обычный запрос.

## Избранное, правка, удаление {#manage}

- **Звёздочка ★** ставит модель в избранное. Избранные показываются первыми и в этом списке, и во всех выпадающих списках выбора; остальные модели провайдера сворачиваются в блок `Остальные модели провайдера`.
- **Карандаш** открывает ту же форму, что и ручное добавление: ID изменить нельзя, всё остальное можно.
- `Удалить модель` убирает её из списков выбора. Записи в журнале остаются, а добавить модель снова можно поиском в каталоге. Модель, которая сейчас выбрана по умолчанию или у какой-то функции, удалить нельзя: сначала выберите там другую.

## Как выбирать модели {#choose}

:::terms accent
[Sparkles] Сильная модель
Большой контекст, рассуждение, высокая цена. Для программы, покрытия, сборки урока. Проверяйте, что на нужном уровне рассуждения она держит структурный ответ.

[Zap] Быстрая среднего класса
Цена в разы ниже, качество достаточное для большинства функций. Разумный выбор по умолчанию.

[Coins] Лёгкая и дешёвая
Для уборки текста, группировки, оценок. Подходит любая модель, которая уверенно отвечает по схеме.

[Eye] Видящая изображения
Нужна для облачного распознавания. Здесь важны точность на формулах и таблицах и скорость, поэтому выбирать стоит по замерам, а не по цене.

[Mic] Модель речи
Для голоса. Хорошо подходят Whisper-модели у провайдеров, которые их отдают.
:::

Советы по выбору:

- **Сравнивайте цену за реальную работу**, а не за миллион токенов. Модель с низкой ценой, которая ошибается и требует повторных запусков, обходится дороже. Ориентир для распознавания: на экране `Распознавание` цена показана за тысячу страниц.
- **Смотрите на контекст.** Если вы собираетесь строить программу по большому учебнику, нужен большой контекст: иначе материал придётся делить на многие запросы.
- **Обновляйте выбор.** Провайдеры регулярно выпускают новые версии. Заглядывайте в `Поиск моделей` раз в месяц-два, а старую модель можно оставить в списке, пока новая не проверена.
- **Не берите слишком дешёвые «китайские» модели для распознавания**: подробности на странице [«Подготовка текста»](/guide?section=prepare-text).
