**Настройка ИИ** отвечает на четыре вопроса: *у кого* брать модели (провайдер), *какие именно* (модели), *что поручить каждой* (функции) и *сколько на это тратить* (лимиты). Всё это собрано на одном экране, `Параметры → ИИ`. Чтобы начать, достаточно первых трёх шагов: остальное можно докрутить позже.

:::info Без ИИ Tentex тоже работает
Библиотека, быстрая подготовка текста, поиск по словам, программа, ручные уроки, календарь подготовки и карточки, созданные вручную, обходятся без внешних моделей. ИИ добавляет чат, помощь с программой и уроками, исследование покрытия, проверку ответов и облачное распознавание. По умолчанию он **выключен**: пока вы не включите переключатель `Разрешить функции с ИИ`, Tentex ничего не отправляет провайдерам.
:::

## Как устроена настройка {#how}

Провайдер, модель и функция связаны цепочкой. Провайдеру нужен ключ, из его каталога вы добавляете модели, а каждая функция берёт одну из добавленных моделей.

:::diagram ai-setup
Слева направо: от ключа до лимитов. Внизу порядок, по которому функция находит себе модель.
:::

Порядок выбора модели для функции простой: **первой берётся то, что вы выбрали в самом запуске** (например, в окне сборки урока или в поле чата), затем **модель самой функции**, затем **модель по умолчанию**. Если не нашлось ничего, функция не запустится и сообщит «Модель для функции не настроена». Поэтому модель по умолчанию — это страховка для всех функций сразу.

Две функции устроены строже. «Обзор материала» и «Исследование материала» (проход 2 покрытия) не имеют запасной модели: их модель выбирается явно, либо здесь, либо в окне запуска. Подробнее об этом на странице [«Функции»](/guide?section=setup-ai-functions).

## Порядок настройки {#order}

:::steps
1. **Включите ИИ.** `Обзор` → `Разрешить функции с ИИ`. Настройки ниже можно менять и при выключенном переключателе, ключи при этом сохраняются.
2. **Подключите провайдера.** `Провайдеры` → `Добавить провайдера`, вставьте адрес и ключ, нажмите `Тест`. Статус должен стать `Отвечает`.
3. **Добавьте модели.** `Модели` → `Поиск моделей`. Для начала хватит двух-трёх: одна сильная, одна лёгкая и быстрая. Для голоса нужна ещё модель речи, для распознавания страниц модель, которая видит изображения.
4. **Назначьте модели по умолчанию.** `По умолчанию`: выберите модель для текста (и для речи, если нужен голос) и нажмите кнопку сохранения. Этого достаточно, чтобы заработали почти все функции.
5. **Усильте тяжёлые функции.** `Функции`: там, где качество важнее цены, выберите сильную модель. Это необязательно.
6. **Поставьте дневной лимит.** `Расходы`: небольшая сумма на первые недели защищает от неприятных сюрпризов.
7. **Загляните в журнал.** Через несколько дней `История` покажет, какие функции дороже остальных.
:::

## Как распределить модели {#recommend}

Функции сильно различаются по сложности. Одни держат в голове всю программу учебника или целую главу, другие поправляют пунктуацию. Платить за сильную модель там, где справится простая, нет смысла. И наоборот: слабая модель на сложной задаче даёт ошибки, которые вы потом вычищаете руками.

| Класс функций | Какая модель нужна | Примеры |
| --- | --- | --- |
| **Тяжёлые**: сохраняют много контекста, ошибка дорогая | Сильная модель, при необходимости с рассуждением `Средний` или `Высокий` | составление и правка программы учебника, обзор и исследование материала, сборка урока, исправление списка вопросов, проверка ответа |
| **Средние**: структурная работа по небольшому куску | Быстрая модель среднего класса | задания урока, дополнение урока, оглавление учебника, разметка файла ответов, блоки и распределение подготовки, карточки, поиск материалов в интернете |
| **Лёгкие**: механическая правка | Почти любая модель, даже самая дешёвая | уборка текста, разделы вопросов экзамена, оценка времени подготовки, рекомендация дня, память раздела |
| **С изображениями** | Модель, которая принимает картинки | распознавание страницы, описание изображений (выбираются в [распознавании](/guide?section=setup-ocr-modes)) |
| **С речью** | Модель распознавания речи | голосовой ввод, расшифровка аудиоматериалов |

:::success Самый простой путь
Не хотите вникать? Добавьте одну надёжную модель среднего класса, сделайте её моделью по умолчанию и **оставьте функции как есть**. Лёгкие функции справятся сразу. А для составления программы и исследования покрытия выберите модель посильнее: это две самые заметные точки, где сильная модель окупается.
:::

Несколько правил, которые экономят время и деньги:

- **Экономьте на лёгком, платите за тяжёлое.** Разница в качестве заметна там, где модель принимает решения по всей программе, а не там, где чистит абзац.
- **Не гонитесь за одной моделью на всё.** Их можно смешивать: у разных функций разные модели, и это нормально.
- **Смотрите на класс, а не на название.** Модели выходят и устаревают каждый месяц. Ориентируйтесь на возможности, цену и контекст в карточке модели, а не на громкое имя.
- **Учтите структурный ответ.** Почти все функции требуют, чтобы модель умела отвечать строго по схеме. Без этого она не появится в списке выбора.
- **Начинайте с малого.** Сначала проверьте функцию на одном уроке или одной странице, посмотрите стоимость в `Истории` и только потом запускайте массово.

:::tip Рекомендуемые провайдеры
Для текста мы рекомендуем **OpenRouter**: один ключ открывает модели разных компаний, а в каталоге видны цены, контекст и возможности. Для речи хорошо подходит **Groq Cloud**. У обоих есть бесплатные лимиты, но условия тарифов меняются, поэтому актуальные цифры смотрите на сайтах провайдеров.
:::

## Что уходит провайдеру {#privacy}

:::warning Внешние модели видят то, что вы им отправляете
Вопрос, ответ, фрагмент материала или картинка страницы уходят на сервер выбранного провайдера, а его правила хранения данных действуют вне Tentex. Для конфиденциальных материалов оставьте ИИ выключенным или используйте локальный сервер моделей. Ключи хранятся на вашем компьютере в зашифрованном виде и в резервные копии не попадают.
:::

Если переключатель `Разрешить функции с ИИ` выключен, в местах, где нужна модель, появляется пояснение «Внешние модели выключены» со ссылкой на этот экран. Ту же подсказку даёт панель `Состояние`: подробнее о ней на странице [«Состояние и фоновые задачи»](/guide?section=status-jobs).
