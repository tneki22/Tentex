Короткий словарь Tentex. Всё, что встретится в интерфейсе и дальше в руководстве, названо здесь одним предложением. Читать подряд не нужно: пробегите глазами группы и возвращайтесь, когда слово окажется незнакомым.

:::tip Как пользоваться словарём
У части терминов есть ссылка «Подробнее» — она ведёт в раздел, где вещь описана целиком. Термины сгруппированы цветом: у каждой группы свой.
:::

## Проект и режимы {#project}

:::terms accent
[Layers] Установка
Ваша копия Tentex на этом компьютере: все проекты, Библиотека и настройки. Учётной записи нет — одна установка, один пользователь.

[FolderOpen] Проект → /guide?section=projects
Отдельное пространство обучения: один предмет, экзамен, курс или книга. У проекта своя *программа*, свои привязки, занятия и прогресс. Проектов может быть сколько угодно, друг на друга они не влияют.

[Route] Режим проекта → /guide?section=create
Один из трёх способов начать: **подготовка к экзамену**, **изучение по учебнику** или **свободное изучение**. Режим определяет, какие разделы есть у проекта и как строится программа.

[Target] Паспорт цели → /guide?section=projects
Ваши ответы на вопросы «зачем, к какому сроку, с какого уровня, в каком темпе». По ним подбираются подсказки ИИ. Паспорт можно править в настройках проекта.
:::

## Материалы {#materials}

:::terms info
[Files] Материал → /guide?section=library
Всё, из чего вы учитесь: файл (учебник, методичка, конспект, презентация, скан), сохранённая веб-страница или видео. Материал попадает в Библиотеку, а из неё подключается к проектам.

[Library] Библиотека → /guide?section=library
Общее хранилище материалов установки. *Один материал — один разбор*: если учебник подключён к двум проектам, текст из него готовится один раз.

[ListChecks] Роль материала
Значение материала для конкретного проекта: **основной**, **дополнительный** или **справочный**. Роль задаётся отдельно в каждом проекте, сам материал при этом один.

[FileText] Подготовка текста → /guide?section=prepare-text
Превращение файла в текст по страницам, с которым можно работать. У цифровых документов текст берётся из самого файла, у сканов — через распознавание.

[ScanText] Распознавание (OCR) → /guide?section=setup-ocr
Чтение текста с картинок, сканов и фотографий страниц. Работает на моделях, которые ставятся на компьютер, либо через облачного провайдера.

[ListTree] Оглавление → /guide?section=outline
Структура материала: главы и разделы. Из него можно быстро получить каркас программы, а его проверка важна для точной привязки.

[BookOpen] Страница, блок, фрагмент
*Страница* — единица материала. *Фрагмент* — кусок текста с адресом (файл, страница, место). *Блок* — заголовок вместе с подчинёнными ему фрагментами: по блокам Tentex проверяет, всё ли в материале рассмотрено.
:::

## Программа и покрытие {#program}

:::terms success
[ListTree] Программа → /guide?section=program
Дерево того, что нужно освоить: **разделы**, **темы** и **подпункты**, до четырёх уровней вложенности. В экзаменационном проекте она называется «Вопросы экзамена».

[Target] Тема и вопрос экзамена
*Тема* — то, что вы осваиваете; в экзамене ей соответствует *вопрос* или билет. Из тем состоит программа, и к каждой можно прикрепить материал.

[BookOpen] Эталонный ответ
Образец, с которым сравнивается ваш ответ. Его можно импортировать вместе с вопросами или написать самому.

[Link2] Привязка → /guide?section=answers
Связь «тема — фрагмент материала»: где именно в источнике об этом сказано. Бывает **машинная** (её предложил ИИ), **подтверждённая**, **ручная** или **снятая**.

[ScanSearch] Покрытие → /guide?section=coverage
Измерение связи в обе стороны: есть ли материал под каждую тему и рассмотрен ли каждый содержательный блок материала. Покрытие ниже 100% — не поломка, а результат измерения.

[Search] Пробел
Тема, под которую пока нет материала, — или блок материала, который не отнесён ни к одной теме. Пробелы показывают, что искать дальше; в свободном изучении они нормальное состояние.

[Sparkles] Построение и соотнесение
Две работы ИИ над материалом. *Построение* собирает программу из материала (по главам); *соотнесение* проходит по блокам материала и предлагает, к каким темам они относятся.
:::

## Занятия {#lessons}

:::terms warning
[GraduationCap] Урок → /guide?section=lessons
Сценарий изучения одной или нескольких тем: ссылки на страницы материала, ваши пояснения и медиа. Урок редактируется как документ.

[NotebookPen] Конспект → /guide?section=conspects
Ваш личный документ по теме: формулы, картинки, автосохранение. Он лежит рядом с темой в рабочей области.

[Layers] Карточка → /guide?section=cards
Вопрос на одной стороне, ответ на другой — для повторения. Карточки есть у экзаменационных проектов; в учебниковых их нет.

[CalendarDays] Моя подготовка → /guide?section=preparation
Календарный план подготовки до даты экзамена: какие вопросы в какие дни. Раздел экзаменационного проекта.

[Timer] Планирование занятий → /guide?section=lesson-planning
Расписание занятий и расчёт окончания по сроку у учебникового проекта. Включается в настройках проекта.

[MessagesSquare] Чат → /guide?section=chat
Разговор с ИИ внутри проекта. Ответы опираются на материалы проекта и сопровождаются ссылками на источник.
:::

## ИИ и модели {#ai}

:::terms accent
[KeyRound] Провайдер → /guide?section=setup-ai-providers
Сервис, у которого вы берёте модели по ключу доступа. Для текста рекомендуем **OpenRouter**, для речи — **Groq Cloud**.

[Cloud] Внешняя модель
Модель, которая работает на сервере провайдера. Всё, что ей нужно для ответа — вопрос, страница, фрагмент, — уходит по сети. Без явного включения ничего не отправляется.

[Cpu] Локальная модель
Модель, которая скачана и работает на вашем компьютере: эмбеддинги для поиска, распознавание. Данные наружу не уходят.

[BrainCircuit] Модель по умолчанию → /guide?section=setup-ai-defaults
Модель, которая выполняет задачу, если вы не выбрали другую: отдельно для текста, речи и изображений.

[Coins] Токены и расход → /guide?section=setup-ai-limits
Токен — доля слова, по которой провайдер считает цену запроса. Расход и дневной лимит видны в `Параметры → ИИ`.

[Sparkles] Эмбеддинги → /guide?section=setup-search-models
Числовые «отпечатки смысла» текста. Благодаря им поиск находит нужное по смыслу, а не только по совпавшим словам. Модель скачивается по кнопке.

[Search] Поиск по смыслу и по словам → /guide?section=setup-search
Поиск по словам работает всегда. Смысловой добавляется, когда установлена модель эмбеддингов и построен индекс.

[Database] Индекс → /guide?section=setup-search-index
Служебная база, которую Tentex строит по материалам, чтобы искать быстро. Индекс можно пересобрать в любой момент.

[Timer] Фоновая задача → /guide?section=status-jobs
Долгая операция — подготовка текста, распознавание, индексация, импорт — идёт в фоне. Ход виден в панели «Фоновые задачи» внизу слева, пока работа продолжается.
:::

## Хранение и перенос {#storage}

:::terms info
[Package] Пакет проекта → /guide?section=projects
Файл `.tentex-project` с одним проектом. Импортируется в другую установку как новый проект.

[Archive] Резервная копия → /guide?section=setup-storage-backups
Файл `.tentex-backup` со всей установкой. Восстановление заменяет текущие данные целиком.

[ShieldCheck] Хранилище → /guide?section=setup-storage
Раздел `Параметры → Хранилище`: где лежат данные, копии, перенос проектов и обслуживание.
:::

## Легко спутать {#pairs}

:::warning Три пары, которые нельзя смешивать
- **Тема и вопрос экзамена.** В экзаменационном проекте узел программы называется вопросом, в учебниковом — темой; путать их с материалом и привязками не нужно.
- **Материал и фрагмент.** Материал — целый файл; фрагмент — его кусок с адресом страницы.
- **Привязка и покрытие.** Привязка — одна связь «тема — фрагмент»; покрытие — итоговый показатель по всем связям.
:::
