**Провайдер** — сервис, у которого Tentex берёт модели: он принимает запросы по интернету (или по локальной сети) и присылает ответы. Провайдеру нужны две вещи: адрес и ключ доступа. Всё остальное, то есть какие модели у него есть и сколько они стоят, Tentex узнаёт сам из каталога провайдера.

:::info Ключ нужен всегда
Tentex не сохраняет провайдера без ключа и не вызывает его без ключа. Если вы подключаете локальный сервер, которому ключ не нужен (например, LM Studio), впишите любое непустое значение.
:::

## Два типа провайдеров {#types}

При добавлении выбирается `Тип провайдера`. Он подсказывает Tentex, как читать каталог моделей.

| Тип | Что это | Что даёт |
| --- | --- | --- |
| `OpenRouter` | агрегатор: один ключ открывает модели разных компаний | полный каталог с ценами, контекстом, возможностями и уровнями рассуждения; стоимость каждого запроса приходит в ответе провайдера |
| `OpenAI-совместимый API` | любой сервис, который разговаривает на протоколе OpenAI: Groq, OpenAI, локальный LM Studio и так далее | каталог обычно беднее: часть данных (цену, возможности) придётся указать вручную |

Практическое правило: **если модель есть у OpenRouter, начните с него**. Провайдеров можно завести сколько угодно и пользоваться ими одновременно: например, OpenRouter для текста и Groq для речи.

## Как добавить {#add}

:::steps
1. Откройте `Параметры → ИИ → Провайдеры` и нажмите `Добавить провайдера`.
2. Заполните форму. `Название` любое, но не повторяющееся (например, «OpenRouter»). `Тип провайдера` выберите из списка. `Базовый URL` вида `https://…/v1`. `API-ключ` вставьте из личного кабинета провайдера.
3. Нажмите `Сохранить провайдера`. Ключ сразу шифруется: обратно в интерфейс он не возвращается.
4. Нажмите `Тест`. Под карточкой появится результат: «провайдер отвечает» и число моделей в каталоге либо причина сбоя.
:::

Адреса для справки (сверяйтесь с документацией провайдера, они бывают другими):

| Провайдер | Базовый URL | Тип |
| --- | --- | --- |
| OpenRouter | `https://openrouter.ai/api/v1` | `OpenRouter` |
| Groq Cloud | `https://api.groq.com/openai/v1` | `OpenAI-совместимый API` |
| Локальный сервер (LM Studio) | `http://localhost:1234/v1` | `OpenAI-совместимый API` |

:::tip Если Tentex запущен в контейнерах
`localhost` внутри контейнера означает сам контейнер, а не ваш компьютер. Чтобы достучаться до сервера моделей на вашей машине, обычно вместо `localhost` указывают `host.docker.internal`. Логин и пароль внутри адреса указывать нельзя: они не принимаются.
:::

## Состояние карточки {#state}

У каждого провайдера в списке видны ключ, подключение, число моделей и адрес.

| Что показано | Что значит |
| --- | --- |
| `Нет ключа` | ключ не сохранён: провайдер не вызывается |
| `Не проверен` | ключ есть, но `Тест` ещё не запускали |
| `Отвечает` | последний `Тест` прошёл, каталог получен |
| `Ошибка` | последний `Тест` не прошёл: неверный ключ, адрес или нет сети |

`Тест` провайдера **бесплатный**: он только запрашивает каталог моделей и ничего не тратит. Проверить, отвечает ли конкретная модель, можно отдельно на странице [«Модели»](/guide?section=setup-ai-models).

Звёздочка слева от названия помечает **избранного** провайдера. Избранное влияет только на порядок в списках: такие провайдеры показываются выше. Ссылка `N моделей` в карточке открывает список его моделей.

## Действия с провайдером {#actions}

Меню `⋯` в карточке содержит три действия:

- `Изменить провайдера`: поменять название, тип, адрес; поле нового ключа можно оставить пустым, если ключ менять не нужно;
- `Удалить API-ключ`: стирает только ключ. Модели, настройки и журнал остаются, ключ можно вставить снова;
- `Удалить провайдера`: удаляет и добавленные модели этого провайдера. Название останется в журнале запросов. Если провайдер выбран моделью по умолчанию или у какой-то функции, сначала выберите там другого.

## Как хранится ключ {#secret}

Ключ шифруется на вашем компьютере, а расшифровывается только в момент запроса. Ключ шифрования лежит рядом с данными установки (файл `installation.secret`) и не хранится в базе.

:::warning Ключи не переезжают вместе с копией
Ни в резервную копию, ни в пакет проекта ключи не попадают. После восстановления копии или переноса на другой компьютер введите ключи провайдеров заново. Если ключ был скомпрометирован, удалите его в личном кабинете провайдера и вставьте новый: этот же экран заменит его.
:::

## Типичные проблемы {#problems}

| Что видите | Что проверить |
| --- | --- |
| `Ошибка` после теста | верный ли `Базовый URL` (нужен корень API вида `…/v1`, а не адрес сайта), не истёк ли ключ, есть ли интернет |
| `Отвечает`, но моделей 0 | у провайдера каталог пуст или он не отдаёт список; модель можно добавить вручную по ID |
| Ключ сохранён, а запросы отклоняются | ключ отозван или закончился баланс: смотрите статус в личном кабинете провайдера |
| Локальный сервер не отвечает | запущен ли он, включён ли его сервер и тот ли порт; из контейнеров нужен `host.docker.internal` |
