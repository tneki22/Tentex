**Задний фон** — оформление всего приложения: спокойная подложка за экранами, включая левую панель. Он ни на что не влияет, кроме настроения: карточки и текст остаются чёткими, а заметность подложки можно выбрать. Настройка находится в `Параметры → Задний фон`.

:::info Это оформление, а не очередь задач
Не путайте `Задний фон` с фоновыми задачами: у них общее слово, но разный смысл. Про долгие операции (подготовка текста, распознавание, индексация) рассказано в разделе [«Состояние и фоновые задачи»](/guide?section=status-jobs).
:::

## Варианты {#options}

Выбор один для всех экранов. Каждый вариант показан плиткой с превью:

| Вариант | Что это |
| --- | --- |
| `Однотонный` | без рисунка: вариант по умолчанию, самый спокойный |
| `Сияние` | два мягких цветных свечения в противоположных углах |
| `Волны` | расходящиеся дуги из угла на цветном градиенте |
| `Плавающие линии` | тонкие линии, которые медленно дрейфуют |
| `Частицы` | россыпь точек со связями |
| `Своё фото` | ваша фотография; плитка активна, когда фото загружено |

## Настройки {#settings}

:::steps
1. Откройте `Параметры → Задний фон` и выберите плитку.
2. Ползунок `Заметность фона` (от 0 до 100% с шагом 1%, по умолчанию 12%) делает подложку ярче или тише. При 0% фон скрыт, при 100% виден без приглушения. Подберите значение, при котором вам удобно читать.
3. Переключатель `Плавное движение` включает анимацию у рисованных фонов. Она останавливается в неактивной вкладке и при системной настройке «уменьшить движение». У `Однотонного` нет ни заметности, ни движения; у `Своё фото` есть заметность, но нет движения.
:::

## Своё фото {#photo}

Кнопка `Загрузить своё фото` принимает JPG, PNG и WebP размером до 20 МБ. Перед сохранением Tentex уменьшает изображение. Фото **хранится только в этом браузере** и никуда не отправляется. Кнопка `Удалить фото` убирает его, и оформление возвращается к предыдущему варианту (или `Однотонному`).

:::tip Какое фото выбрать
Подойдёт спокойное изображение без мелких деталей и резких контрастов: интерфейс наложен поверх, и рябь в фоне утомляет. Если фото выглядит слишком заметным, уменьшите `Заметность фона`.
:::

## Добавление своего TSX-фона {#custom}

TSX — исходный код React-компонента на TypeScript. Чтобы добавить новый фон, передайте файл агенту, который может изменить код Tentex. Подойдёт компонент, рисующий сам декоративный эффект: градиент, линии, частицы, узор, SVG или canvas. Файл демонстрационной страницы, который только импортирует фон, сам по себе недостаточен.

Можно выбрать готовый эффект в [коллекции фонов 21st.dev](https://21st.dev/community/components/s/background): откройте понравившийся вариант, скопируйте исходный код компонента и сохраните его в файл с расширением `.tsx`, например `aurora-background.tsx`. Компоненты с Tailwind или Motion тоже можно передать агенту — он адаптирует их под Tentex.

1. Подготовьте TSX с самим эффектом. Если нужны отдельные CSS-файлы, вспомогательные компоненты, изображения или другие ресурсы, приложите их тоже. Укажите используемые библиотеки и ссылку на исходный компонент.
2. В настройках фона нажмите **«Копировать промпт для агента»**.
3. Передайте агенту промпт, файлы и доступ к коду Tentex. Он добавит фон в список пресетов, адаптирует стили, превью и остановку анимации.
4. После изменения кода и пересборки приложения откройте «Задний фон», выберите новый вариант и настройте заметность.

Поле «Загрузить своё фото» принимает только изображения. TSX в нём не загружается и не исполняется; для добавления компонента требуется изменение кода приложения.

## Что нужно знать {#notes}

- Настройка хранится **в браузере**, а не в базе. В другом браузере или на другом компьютере фон придётся выбрать заново. В резервные копии и пакеты проектов он не входит.
- Новые анимированные фоны добавляются через код проекта. Кнопка `Копировать промпт для агента` копирует готовую инструкцию для помощника-программиста. Это для тех, кто хочет добавить свой фон: обычному пользователю она не нужна.
