**Модель эмбеддингов** переводит текст в набор чисел, «отпечаток смысла»: близкие по смыслу тексты получают близкие отпечатки. Благодаря этому поиск находит нужное место, даже если в запросе другие слова. Такие модели небольшие, работают на вашем компьютере и не требуют ключа. Именно поэтому Tentex предлагает **скачать** их, а не подключать по сети.

Для чего вообще нужна модель, объясняет [обзор поиска](/guide?section=setup-search). Здесь разберём, что выбрать, как поставить и проверить.

## Что предлагается {#catalog}

В `Параметры → Поиск → Модели` есть четыре рекомендованные модели. Скачиваются они с Hugging Face, а код репозитория при этом **не запускается**: берутся только файлы весов.

| Модель | Пометка | Для чего |
| --- | --- | --- |
| `Multilingual E5 Base` | `Проверена в Tentex` | стандартный выбор для поиска по учебным материалам |
| `Qwen3 Embedding 0.6B` | `Настройки подготовлены` | альтернатива E5, более требовательная к ресурсам |
| `MiniLM multilingual` | `Для коротких текстов` | лёгкая модель; качество поиска по длинным отрывкам не проверено |
| `Qwen3 Reranker 0.6B` | (для режима `Точно`) | перечитывает лучшие места, о нём ниже |

Каждая занимает порядка гигабайта (MiniLM около половины). Скачивание идёт в фоне, окно можно закрыть.

### Что значат пометки

Рядом с моделью стоит **честная оценка**: с какими моделями поиск проверен, а с какими нет.

| Пометка | Что значит |
| --- | --- |
| `Проверена в Tentex` | модель прогнана на контрольных запросах по настоящей Библиотеке с текущей нарезкой куска. Можно доверять |
| `Настройки подготовлены` | Tentex подставляет нужные настройки запроса и текста, но качество поиска по учебным материалам ещё не проверено |
| `Для коротких текстов` | модель рассчитана на короткие тексты; качество поиска по длинным отрывкам в Tentex не проверено |
| `Настройки неизвестны` | для модели не заданы специальные настройки запроса и текста; получение вектора не гарантирует хорошего поиска |

:::success Что мы рекомендуем
Для повседневной работы рекомендуем модели из встроенного списка, прежде всего **`Multilingual E5 Base`** с пометкой **`Проверена в Tentex`**. Другие модели Hugging Face и модели через внешний API добавляйте для экспериментов: их совместимость с Tentex и качество поиска не гарантированы, даже если проверка профиля прошла успешно.
:::

## Как поставить и проверить {#install}

Для каждой модели три действия, и для рекомендованных они идут по порядку:

:::steps
1. `Скачать`. Появится полоса «N из M файлов». Статус станет `Установлена`.
2. `Добавить профиль`. *Профиль* — запись «эта модель + её настройки», из которой строится индекс. Кнопка есть только у моделей эмбеддингов.
3. `Проверить`. Tentex проверит получение вектора и покажет его размерность. Это позволяет собрать индекс, но не оценивает качество поиска. Первый проверенный профиль **сам становится профилем для новой сборки**.
:::

Если проверка не прошла, причина показана красным. Кнопка `Проверить` доступна только у полностью установленной модели: пока идёт скачивание, она неактивна.

`Удалить` стирает файлы модели. Если по ней уже построен индекс, Tentex откажет: «Модель используется индексом; сначала удалите неактивные индексы». Активный индекс удалить нельзя, поэтому, чтобы убрать модель, сначала постройте и активируйте индекс на другой модели.

## Добавить свою модель {#manual}

Блок `Добавить модель вручную` позволяет добавить другую текстовую модель эмбеддингов с Hugging Face. Нужна совместимость с Transformers без дополнительного кода из репозитория. Впишите идентификатор в формате `owner/model`, при желании название, и нажмите `Добавить модель`: Tentex заведёт профиль и сразу поставит модель на скачивание.

Что важно знать:

- Для моделей семейств E5, Qwen3 Embedding и BGE-M3 Tentex сам подставляет нужные настройки запроса и преобразования текста в вектор. Для других моделей эти настройки могут быть неизвестны.
- Новая модель начинает работать только после нового индекса: старые векторы построены другой моделью.
- Свою модель имеет смысл добавлять, только если вы знаете, что она хорошо работает с русским языком.

## Внешняя модель через API {#external}

Блок `LM Studio или внешний API` подключает модель эмбеддингов, которая живёт не у вас в Tentex, а у провайдера (или в локальной программе вроде LM Studio). Он использует подключение из [`Параметры → ИИ`](/guide?section=setup-ai-providers): выберите `Провайдер`, затем `Embedding-модель`, нажмите `Добавить профиль`. Tentex сразу проверит её настоящим запросом и покажет число измерений.

В списке моделей показаны только те, что похожи на эмбеддинги: reranker и чатовые модели туда не попадают.

:::warning Внешние эмбеддинги отправляют тексты провайдеру
Для построения индекса тексты ваших материалов будут уходить выбранному провайдеру. Это платно и не для конфиденциального. Перед сборкой Tentex покажет материалы и объём и попросит подтвердить. Если материалы приватные, используйте локальные модели.
:::

## Reranker {#reranker}

*Reranker* — вторая модель, которая работает после поиска. Она читает вопрос вместе с каждым из лучших мест (десять кандидатов) и оценивает, действительно ли место отвечает на вопрос. Это точнее, чем сравнение отпечатков, но медленнее: на процессоре порядка 15–20 секунд на запрос.

Reranker **необязателен** и нужен только для режима `Точно`. Скачивается так же, кнопкой `Скачать`; профиль ему не нужен. Пока модель не установлена, вкладка `Точно` в блоке `Дополнительно` недоступна и подсказывает: «Нужна установленная модель reranker: скачайте её на вкладке «Модели»». Подробнее в [«Качестве и пресетах»](/guide?section=setup-search-quality).
