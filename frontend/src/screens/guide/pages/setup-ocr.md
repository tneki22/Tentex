**Распознавание** — то, что превращает ваш файл в текст, с которым дальше работает всё остальное: поиск, программа, уроки, чат. Файл, из которого текст можно просто взять (DOCX, TXT, PDF из Word или LaTeX), распознавания не требует. Оно нужно там, где текста нет: на сканах, фотографиях страниц, в формулах и рисунках. В `Параметры → Распознавание` вы решаете, чем читать такие страницы и как аккуратно это делать.

:::info Порядок работы описан в разделе «Подготовка текста»
Как запускать подготовку, когда выбирать `Быстро`, а когда `Облако` и как работают стратегии, рассказано на странице [«Подготовка текста»](/guide?section=prepare-text). Здесь только **настройка**: что где включить, что делает каждая опция и какие параметры задать моделям, чтобы всё заработало.
:::

## Что и где настраивается {#map}

Настройки распознавания задают **значения по умолчанию**. Перед каждым запуском в панели `Обработка` (Библиотека, экран материала) их можно поменять для одного запуска. Запущенный разбор ничего не меняет: у него собственный снимок настроек, поэтому пауза, повтор и смена параметров посреди работы книгу не «переключают».

:::diagram ocr-settings
Слева настройки установки, в центре панель запуска, справа задача со снимком параметров.
:::

Экран `Параметры → Распознавание` состоит из четырёх блоков:

| Блок | Что там | Подробно |
| --- | --- | --- |
| `Обзор` | `Нагрузка при быстром разборе`, `Режим по умолчанию` и сводка по обоим режимам с их состоянием | [режимы](/guide?section=setup-ocr-modes) |
| `Режимы` | настройки `Быстро` (версия распознавателя) и `Облако` (стратегия, модель) | [режимы](/guide?section=setup-ocr-modes) |
| `Установка` | локальные модели распознавания: скачать, остановить, удалить | [установка моделей](/guide?section=setup-ocr-install) |
| `Качество` | порог «нужно проверить» и подробность картинки страницы | [качество](/guide?section=setup-ocr-quality) |

## Что нужно вам {#need}

Не всё из этого требуется каждому. Посмотрите на свои материалы и возьмите только нужное.

| Ваши материалы | Что настроить |
| --- | --- |
| Текстовые файлы: DOCX, TXT, MD, PDF из Word или LaTeX, конспекты | **ничего**: текст берётся из файла, распознавание не запускается |
| Сканы и фотографии печатного текста | [установить локальную модель](/guide?section=setup-ocr-install): бесплатно, без интернета |
| Формулы, таблицы, схемы, сложная вёрстка, рукопись | [облачный режим](/guide?section=setup-ocr-modes#cloud): провайдер и модель, которая видит изображения |
| Записи лекций и голосовые | расшифровка `Локально` не требует настройки; для `Облака` нужна модель речи в [моделях по умолчанию](/guide?section=setup-ai-defaults) |

## Порядок настройки {#order}

:::steps
1. **Ничего не делайте, пока не понадобится.** Для текстовых файлов настройка не нужна. Локальная модель обычно подтягивается сама при первом скане, но удобнее поставить её заранее.
2. **Установите локальную модель.** `Установка` → `Установить`. Она небольшая и работает на процессоре без интернета. Подробнее в [установке моделей](/guide?section=setup-ocr-install).
3. **Выберите нагрузку.** `Обзор` → `Нагрузка при быстром разборе`. Если компьютером надо пользоваться во время разбора, оставьте `Сбалансированный` или выберите `Бережный`.
4. **Оставьте `Быстро` режимом по умолчанию.** Сначала быстрый проход по всем файлам, облако потом точечно: так вы не платите за то, что не нужно.
5. **Подключите облако, когда понадобятся формулы.** Провайдер и модель в [настройке ИИ](/guide?section=setup-ai), затем `Режимы` → `Облако`: стратегия и модель. Проверьте модель на одной-двух страницах.
6. **Настройте качество только при необходимости.** Значения по умолчанию подходят большинству материалов.
:::

## Как понять, что всё готово {#ready}

Каждый режим на `Обзоре` показывает **состояние** цветной плашкой:

| Состояние | Что значит |
| --- | --- |
| `Готов к работе` | можно запускать |
| `Загружаются модели` | идёт скачивание локальной модели |
| `Нужны модели` | для `Облака` не выбрана модель распознавания |
| `Ошибка` | у провайдера выбранной модели нет ключа |
| `Пока не подключён` | внешние модели выключены: включите их в `Параметры → ИИ` |

У `Быстро` состояние почти всегда `Готов к работе`, даже без скачанных моделей: текстовый PDF разбирается без них, а первый скан подтянет модель сам. В подписи под плашкой Tentex поясняет, чего не хватает.

Общая сводка есть и в панели `Состояние` (левая панель, внизу): строки про распознавание сообщат, если выбранный по умолчанию режим не готов. Подробнее в [«Состоянии и фоновых задачах»](/guide?section=status-jobs).

:::warning Облачный режим отправляет страницы провайдеру
Картинки страниц или вырезы с формулами уходят на сервер выбранного провайдера. `Быстро` ничего не отправляет: всё считается у вас на компьютере.
:::

## Куда что ложится {#storage}

Файлы локальных моделей лежат рядом с вашими данными (`data/models`) и работают без интернета. Они не входят в резервные копии и в пакеты проектов: на другом компьютере модели нужно установить заново.
